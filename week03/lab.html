Part 1 — Math check: sigmoid, odds and log loss by hand

⏱ 15 min
Goal: Compute the sigmoid, the odds, the log-odds and the log loss yourself in NumPy, then compare with SciPy and scikit-learn.

These are the formulas from the Math toolkit slides: p = 1 / (1 + e−z), odds = p / (1 − p), log-odds = ln(odds) = z, and log loss = −average[y·ln p + (1 − y)·ln(1 − p)]. If your hand results match the library, you know the library is “just the formula”.

from sklearn.metrics import log_loss
from scipy.special import expit                            # scikit-learn's sigmoid

# --- sigmoid by hand: z = 1.2*HighBP + 0.9*BMI_z - 2.0 for three patients
z = 1.2 * np.array([0, 1, 1]) + 0.9 * np.array([-1, 0, 2]) - 2.0
p_hand = 1 / (1 + np.exp(-z))
print("z      =", z.round(2))
print("p hand =", p_hand.round(3), " expit:", expit(z).round(3), " match:", np.allclose(p_hand, expit(z)))
print("odds   =", (p_hand / (1 - p_hand)).round(3), " log-odds =", np.log(p_hand / (1 - p_hand)).round(2))

# --- log loss by hand on the 4 slide predictions
y4 = np.array([1, 1, 0, 0]); p4 = np.array([0.9, 0.6, 0.2, 0.95])
each = -(y4 * np.log(p4) + (1 - y4) * np.log(1 - p4))
print("loss per patient =", each.round(3))
print("log loss hand = %.3f  sklearn = %.3f" % (each.mean(), log_loss(y4, p4)))

# --- log loss of the 'always say the base rate' baseline on the real test set
base = y_train.mean()
ll_hand = -(y_test * np.log(base) + (1 - y_test) * np.log(1 - base)).mean()
print("base rate %.4f -> baseline log loss hand %.4f  sklearn %.4f" % (base, ll_hand, log_loss(y_test, np.full(len(y_test), base))))

Why it works

z = [−2.9, −0.8, 1.0] gives p = [0.052, 0.310, 0.731], identical to expit. The odds are [0.055, 0.449, 2.718], and the log-odds come back to exactly z: the log-odds is the weighted sum. The confident mistake (p = 0.95 for a healthy person) costs 2.996 on its own, while the three reasonable predictions cost 0.105, 0.511 and 0.223, so the average is 0.959. The base-rate baseline scores 0.4039 on the real test set: that is the number a real model must beat.

Part 3 — Math check: distance by hand, then kNN

⏱ 20 min
Goal: Compute Euclidean and Manhattan distances yourself, find a real patient's 15 nearest neighbours by hand, then check that KNeighborsClassifier finds the same ones, and see what happens without scaling.

kNN has no weights to learn: it stores the training rows and lets the k closest ones vote. Euclidean distance is √Σ(difference²), Manhattan distance is Σ|difference|. Because distances add up raw differences, features must be scaled first.
